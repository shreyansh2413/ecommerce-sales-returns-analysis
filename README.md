# E-Commerce Sales & Returns Analysis

## Project Overview

This project analyzes e-commerce sales performance, profitability,
customer behavior, and product returns using Python, PostgreSQL,
SQL, and Power BI.

The objective is to identify key business trends, high-performing
products and categories, and return-related issues that can help
businesses improve revenue and profitability.

## Tools Used

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI
- Excel

## Dataset

The dataset contains five related tables:

- Customers
- Products
- Orders
- Order Items
- Returns

The dataset is synthetic and covers e-commerce transactions
from 2024–2026.

## Data Analysis Process

1. Data understanding using Python/Pandas
2. Data quality checks
3. Relational database creation in PostgreSQL
4. SQL-based business analysis
5. Power BI data modeling
6. Dashboard development
7. Business insights and recommendations

## Key Business Questions

- What is the total revenue?
- What is the Average Order Value?
- Which categories generate the highest revenue?
- Which products generate the most revenue?
- What is the overall return rate?
- Which categories have the highest return rate?
- What are the most common return reasons?
- Which products have high sales and high return rates?
- Which customers have high spending and high returns?
- How does monthly revenue change over time?

## Power BI Dashboard

The dashboard provides:

- Total Revenue
- Total Orders
- Average Order Value
- Total Profit
- Return Rate
- Monthly Revenue & Profit
- Revenue by Category
- Orders by Status
- Top 10 Products by Revenue

## Key Findings

### Revenue Performance

Toys & Games generated the highest category revenue,
followed by Beauty and Home & Kitchen.

### Order Performance

The majority of orders were delivered, while smaller portions
were cancelled, shipped, and processing.

### Product Performance

The Top 10 Products analysis highlights the products generating
the highest revenue and helps identify important products within
each category.

### Returns

The project analyzes return rate, refund amount, return reasons,
return timing, and non-restocked returns to identify potential
operational and product-level issues.

## Business Recommendations

- Investigate products with high revenue but unusually high
  return rates.
- Analyze the most common return reasons by category.
- Focus on improving product descriptions and quality for
  frequently returned products.
- Monitor non-restocked returns because they can increase
  financial losses.
- Use high-performing products and categories to guide
  inventory and marketing decisions.

## Business Impact

The analysis helps answer three major business questions:

1. Where is the revenue coming from?
2. Which products/categories are driving profitability?
3. Where are returns creating potential revenue leakage?

The dashboard allows stakeholders to quickly monitor sales,
profitability, order status, and return performance.
